\section{Reproduction}

\begin{verbatim}
make venv     # python3.12; torch from the cu130 index, which the default build lacks
make venv-gpu # optional; without it two parity claims cannot hold, see below
make smoke    # S0-S8 environment assertions; any failure stops the build
make reproduce
make check    # rebuilds the PDFs, then the claim, citation and manifest gates
\end{verbatim}

\paragraph{A fourth clean-room run, \Record{2026-09-06}.} From an empty directory,
\Record{28} of the \Record{34} tables committed at that date are byte-identical and five more
agree in every measured value, differing only in wall-clock seconds --- including the
full-scale tensor-network fits, exact to the last digit across a rebuilt CUDA stack. All
\Record{102} bound claims passed, and the run reached the manifest comparison rather than
halting before it. The third run, a day earlier, left nine failing: latency, whose every value
is a timing, and parity, which needs the optional extra above. Both now report a skip and keep
the committed table rather than overwrite it, so a reviewer's run says what it did not verify.

\paragraph{Two environment traps, both silent.} \texttt{qiskit-aer} and
\texttt{qiskit-aer-gpu-cu11} install the \emph{same} package, so whichever pip unpacks last
wins: the CPU build can land second and Aer then reports devices \texttt{('CPU',)} with no
error anywhere, turning a GPU cross-check into a second CPU run. The GPU wheel is reinstalled
last and a smoke check reads the device from \texttt{nvidia-smi}. Chained assignment is
likewise a no-op under pandas copy-on-write; a gate forbids the pattern repository-wide.

\paragraph{Every measured number in both documents is generated.} \texttt{docs/claims.yaml} binds each
quoted figure to a table row; \texttt{scripts/check\_claims.py} recomputes all of them from
\texttt{results/tables/*.csv}; \texttt{scripts/make\_tex.py} emits them as macros and renders
the results tables from the same CSVs. \texttt{scripts/check\_pdf.py} then asserts page count,
paper size and font floor against the built PDF and scans the sources for numeric literals, so
a typed number is a defect review can see.

\paragraph{Licensing.} Code is Apache-2.0 with an SPDX header on every file, enforced by test.
Raw data is never committed: IEEE-CIS is distributed under Kaggle competition rules rather than
an open licence, and section~7.A of those rules restricts it to non-commercial research, which
is one reason a Phase~II sprint must move to the issuer's own stream.
\texttt{cuquantum-cu11} arrives under NVIDIA's proprietary SLA, which is why the extra above
is optional and why no scientific figure depends on it. The conformal implementation was
written from the published papers rather than adapted from an unlicensed repository, and that
decision is recorded with its date.
